# 모모의 이슬정원

바탕화면 위 작은 정원에서 모모를 돌보는 Windows 방치형 육성 게임입니다.

## 게임 다운로드

**[Windows 공개 테스트 다운로드](https://github.com/kirby-gpt/momo-dew-garden/releases/tag/v0.14.0-public-test.1)**

릴리스 페이지의 Assets에서 Windows-x64.zip을 받아 **모두 압축 풀기** 후 **MintPet.exe**를 실행하세요. Unity 설치는 필요 없습니다. 위쪽 Code → Download ZIP은 게임 다운로드가 아닙니다.

- 먹이 주기·쓰다듬기·수면·연못에서 씻겨 주기
- 이슬받기·사천성·같은 그림 맞추기·스네이크
- 의상 30종과 장식품 30종, 정원 꾸미기와 상호작용
- 친밀도별 대사와 컴퓨터 시간에 맞춘 낮/밤
- 실제 초파리 연결 자료를 활용한 단순화 신경 시뮬레이션

![모모의 이슬정원 설명서](https://github.com/kirby-gpt/momo-dew-garden/releases/download/v0.14.0-public-test.1/Momo-Game-Guide-KO.png)

## 테스트판 안내

Windows 10/11 64비트용이며 현재 디지털 서명이 없는 테스트 빌드입니다. 로컬 저장 방식으로 클라우드 저장과 자동 업데이트는 없습니다. 업데이트 전 저장 폴더를 백업하세요. 자세한 조작·저장 안내는 게임 ZIP 안의 START-HERE-KO.txt를 참조하세요.

이 게임은 실제 의식·감정·언어의 재현이 아니며, 현재 시냅스 가소성 학습은 구현되어 있지 않습니다.

**[버그 제보하기](https://github.com/kirby-gpt/momo-dew-garden/issues)** — Windows 버전, 사양, 화면 배율과 재현 순서를 적어 주세요. 로그를 공개 첨부하기 전에 개인정보를 확인하세요.

이 저장소는 공개 테스트 배포와 안내용입니다. 자료 출처와 라이선스는 배포 패키지의 THIRD-PARTY-NOTICES.txt 및 동봉 MIT 고지에서 확인할 수 있습니다.
